# AWS Machine Learning - Summary

- **Rekognition**: image & video analysis (labels, faces, celebrities)  
- **Transcribe**: speech-to-text (e.g., subtitles)  
- **Polly**: text-to-speech conversion  
- **Translate**: language translation  
- **Lex**: build conversational chatbots  
- **Connect**: cloud-based contact center with ML features  
- **Comprehend**: natural language processing (sentiment, entities, key phrases)  
- **SageMaker**: build, train, and deploy custom ML models  
- **Kendra**: intelligent, ML-powered search engine  
- **Personalize**: real-time personalized recommendations  
- **Textract**: extract text and structured data from documents
